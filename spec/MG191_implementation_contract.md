## Inputs and eligibility

Deterministic input backgrounds are constructed once from the frozen prescriptions and Newton solver, stored locally with a,b,x,G/X/Y and spectral backgroundGgradient, and hashed into the published plan. This is input construction, not a particle-direction evaluation. Cached reference hashes are retained. No seeds are needed: no stochastic process is sampled. Existing models/reference caches remain unchanged.

31 qualification jobs:16uniform nonlinear viability trajectories plus15background stability checks for the distinct production backgrounds. Viability uses exact discrete homogeneous Fourier-mode eigenvalues, then T400 with cached reference perturbation at0, samples.5. Every observation from100 onward must retain the original singlecore, depth>=.6reference, width.75..1.25reference. A failed scientific criterion is a completed but nonqualifying job, not a replacement candidate. Production's common coarse epsilon grid requires bothaextremes and bothbextremes to qualify, preserving comparableA/R/C arms. FineH additionally requires its matching fineaextremes. Each production background must independently pass stability. N/L remain control cases when their own background passes. Fewer than two common coarseeps blocks production altogether; no alternative eps is substituted.

Nonuniform stability uses ARPACK six largest-real eigenpairs plus twelve shift-invert eigenpairs nearzero, nonconstant deterministic startvector, eigenpair residual<1e-5, maximum observed realpart<−1e-8. Local-extrema homogeneous spectra include every discrete Fourier mode. These are numerical spectral checks, not rigorous real-arithmetic stability certificates. Nonconvergence is an implementation failure and stops the controller; it is not relabeled physical instability.

## Core identity, integration and observations

The X perturbation is relative to the frozen backgroundX for that arm. A core candidate is a local minimum deeper than half the cached referenceXdepth. More/fewer than one candidate, absent flankingzeros, or displacement exceeding half a referencewavelength between adjacent observations permanently invalidates the original track; later isolated cores do not restore its identity. Center is the midpoint of the nearest flanking linearly interpolated zeros, depth is the sampled coreminimum, width is the zero-to-zero separation. Referencewidth/depth use the identical calculation. Shape thresholds are applied after500 for production, after100 for viability.

BDF uses rtol1e-8/atol1e-10/maxstep.5 and consecutive50timeunit calls with exact endpoint continuity. Numerical restart at each50unit checkpoint is disclosed; both meshes and all arms share it. Each checkpoint stores all sampledG/X/Yfields (101frames), times, initial/final states in compressed localNPZ. Adjacent blocks share the endpoint; joined observations remove one duplicate. No hidden forcing or reseeding. Every.5observation's corecount,center,depth,width and original-valid flag is saved. This full local field archive permits independent reconstruction of all decisions, including missing or ambiguous cases. Public outputs are compact only.

R uses the mirror start−x_j with−epsilon. Its null floor is the absolute floor from the correspondingN(+x_j), under reflection symmetry of the unchanged lattice/reference (verified during implementation), without adding extra null trajectories. Force is the periodically interpolated frozen−Ggradient, averaged along each50unit interval. Matching null floors use the maximum absolute post500 interval speed, min1e-10. Reverse-pair envelope is the sum of matching absolute null floors (each>=1e-10), applied to paired interval velocities. Median absolute speed must exceed10*floor to resolve a case. Numerical/mesh uncertainty is not interpreted as a stochastic confidence interval.

Any candidate calledSUPPORTED must meet all approvedP1*/P4* criteria, shape/identity validity and level-control advisory check. Arrival within one cached wavelength of theactualbackgroundGminimum is reported separately, censored if never attained. No finite-time arrival gate or new amplitude threshold.
