## Execution controls

Local PC, <=8 owned worker processes; OPENBLAS/MKL/OMP/NUMEXPR threads each1 before numerical imports. Aggregate charged production ceiling216000 worker-seconds (60core-hours), per-job elapsed timeout3600seconds, controller polling .25seconds. Job wall charge includes imports, compilation, sampling, checkpoint compression, serialization, failures and termination latency. Controller stops the entire batch on a failed/nonzero-exit worker, timeout or aggregate cap; no automatic retry/resume. A worker also checks its own elapsed limit between checkpoints. Tiny polling/termination overshoot, if any, is disclosed from the actual ledger.

Before dispatch, require remaining forecast plus unfinished active forecast <=75% of unspent cap. Per-path forecast is the matching T.1 measured kernel seconds times600 times1.25, plus5seconds for startup/checkpoint overhead. Total about41.68core-hours fits the45-hour planning threshold. This is a forecast, not a late-time bound; runtime can change with populations and safety adaptation. Timeout/cap produces an incomplete outcome and retained partial evidence, not a scientific null.

Checkpoint streaming calls the unchanged qualified numerical event kernel with a persistent Numba random stream. A snapshot written at each integer time contains all preceding22-row checkpoints, actual initial state and denominators, external flags, times, seed and cumulative safety stats. Atomic replacement retains the latest valid archive on interruption. There is no checkpoint-based restart/reseed. Every checkpoint's per-site integer ledger, global external-input balance, maintained-stock invariance, nonnegativity and probability safety must pass. In-flight failures retain their last valid checkpoint and progress record; failed attempts stay in the denominator.
